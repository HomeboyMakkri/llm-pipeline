## Цель и поток данных

CLI читает исходный текст из `stdin`. `prompts.py` формирует сообщения, `llm_client.py` отправляет их в DeepSeek и возвращает строку. Затем программа разбирает JSON, проверяет поля и типы по схеме и использует значения для построения вывода. Если строка не разбирается или объект не соответствует схеме, CLI пишет понятное сообщение в `stderr` и завершает работу с ненулевым кодом.

JSON задаёт синтаксис ответа, а схема — его структуру. В Day 3 `category` используется как метка в выводе. Фиксированные категории запросов, `intent` и маршрутизация входят в [Day 4](../tasks/day04.md).
