## Цель и поток данных

CLI читает текст из `stdin`. Первый вызов модели возвращает `category` (одну из фиксированных меток) и `intent` (краткое описание того, чего хочет автор). После проверки результата код выбирает инструкцию по `category`. Второй вызов получает исходный текст, `intent` и выбранную инструкцию, затем возвращает содержательную часть ответа. CLI сохраняет краткое содержание, тональность, три ключевые мысли и итоговый ответ из Day 3; категорию и намерение берёт только из результата классификации.
