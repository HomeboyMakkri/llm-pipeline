# Спецификация

## Назначение

Учебный Python-проект для изучения LLM API и построения пайплайна обработки текста. Общее задание и критерии по этапам находятся в `tasks/overall.md` и `tasks/day01.md`–`tasks/day07.md`.

## Текущие решения

- Первый провайдер — DeepSeek через совместимый API; клиент использует библиотеку `openai` и загружает `.env` через `python-dotenv`. Настройки: `DEEPSEEK_API_KEY`, `LLM_BASE_URL` и `LLM_MODEL`. Формирование запроса и извлечение ответа проверены локально без сетевого обращения; реальный вызов API ещё не проверен.
- Виртуальное окружение находится в `.venv` в корне проекта; README описывает установку в него и текущее состояние проекта.
- Проект развивается по дням; функциональность следующих дней не считается реализованной заранее.

## День 1

Программа принимает произвольный текст без изменения исходного кода и обращается к модели. Ожидаемый результат содержит краткое содержание, три ключевые мысли и короткий полезный ответ; его можно просмотреть в читаемом структурированном виде.

Запуск: `python -m llm_pipeline.main`. Программа читает текст из стандартного ввода до конца потока и выводит ответ модели. Поток локально проверен с подставным HTTP-ответом без обращения к API.

Вызов API, шаблон промпта и сборка программы разделены. Подготовлены минимум три примера; критерий дня включает их реальный прогон через API и проверку результатов. Локальные проверки могут дополнять этот прогон, но не заменяют его.

Строгая схема, формальная валидация и расширенная обработка сбоев относятся к следующим этапам по ТЗ. Формат первого ответа не следует считать гарантированным только потому, что он запрошен в промпте.
