# LLM Text Pipeline

Учебный проект по созданию пайплайна обработки текста с помощью LLM. Программа связывает промпт и клиент DeepSeek; реальные запросы к клиенту выполнены в эксперименте [Day 2](docs/PLAN_DAY2.md), штатный CLI в нём не запускался. Задания находятся в [`tasks/`](tasks/), текущие решения — в [SPEC.md](SPEC.md), план первого дня — в [docs/PLAN_DAY1.md](docs/PLAN_DAY1.md).

## Окружение

Требуется Python 3.10 или новее. Команды выполняются из корня проекта. Виртуальное окружение находится в `.venv`; если его нет, создайте:

```bash
python3 -m venv .venv
```

Активируйте окружение и установите проект с зависимостями:

```bash
source .venv/bin/activate
python -m pip install -e .
```

В Windows PowerShell для создания и активации используйте:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e .
```

Проверить установку без запроса к API:

```bash
python -c "import openai, dotenv, llm_pipeline; print('Зависимости доступны')"
```

Для выхода из окружения выполните `deactivate`.

## Конфигурация DeepSeek

Скопируйте `.env.example` в `.env` в корне проекта (`cp .env.example .env` в Linux/macOS или `Copy-Item .env.example .env` в PowerShell). Укажите ключ DeepSeek в `DEEPSEEK_API_KEY` локально, не передавая его в чат и не добавляя в Git. `.env` исключён из Git. `LLM_BASE_URL` и `LLM_MODEL` задают адрес API и модель; при необходимости их можно изменить.

Клиент `llm_pipeline.llm_client.get_response(messages)` загружает `.env` через `python-dotenv`, отправляет готовый список сообщений и возвращает текст ответа. `prompts.py` формирует `system` с общими правилами и `user` с задачей и исходным текстом. Переменные, уже заданные в окружении, имеют приоритет. Клиент и CLI проверены локально с подставным HTTP-транспортом; клиент также проверен реальными запросами в эксперименте Day 2. Запросы к API расходуют баланс. Команда проверки установки выше к API не обращается.

В пользовательском сообщении шаблон отделяет инструкцию от исходного текста и запрашивает разделы «Краткое содержание», «Ключевые мысли» и «Итоговый ответ» в этом порядке. Подстановка многострочного текста с фигурными скобками проверена локально без вызова API.

## Запуск

Из корня проекта с активированным окружением выполните:

```bash
python -m llm_pipeline.main
```

Введите текст и завершите ввод: в Linux/macOS нажмите Ctrl+D на новой строке, в Windows — Ctrl+Z и Enter. Можно также передать текст из файла:

```bash
python -m llm_pipeline.main < input.txt
```

Программа передаст текст модели и выведет её ответ. Запуск делает реальный платный запрос к API. Формат ответа не гарантирован; локальная проверка потока с подставным ответом не заменяет реальный прогон.
