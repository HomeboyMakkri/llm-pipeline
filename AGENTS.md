# Правила работы над проектом

- Это учебный проект: перед реализацией кратко объясняйте цель, поток данных и новые понятия; после неё — изменения и результаты проверок. Отвечайте на вопросы по коду на русском языке, сохраняя английские имена API и идентификаторов.
- Работайте только над выбранным пользователем этапом или шагом. Не начинайте следующий без запроса; после шага остановитесь для разбора и вопросов. Исходные задания находятся в `tasks/`, согласованные решения — в `SPEC.md`, пошаговый план Day 1 — в `docs/PLAN_DAY1.md`.
- Пишите понятный код без преждевременных абстракций и лишних сущностей. Разделяйте вызовы API, промпты и логику программы; зависимости добавляйте по мере необходимости.
- Не помещайте ключи в код, документы, логи или Git. Не запрашивайте ключ в чате. Реальные вызовы API расходуют баланс.
- Проверяйте изменённое поведение подходящим способом. Отдельно сообщайте о локальных проверках и реальных запросах к API; не выдавайте имитацию за проверку провайдера.
- Сохраняйте существующую работу пользователя. Обновляйте спецификацию и план при согласованных изменениях и по фактическим результатам.
- Отмечайте пункты плана выполненными только после реализации и соответствующей проверки; фиксируйте ограничения и фактические результаты, не выдавая предположения за проверенные факты.
